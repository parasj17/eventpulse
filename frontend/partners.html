Partner API

Give every ticket buyer a live way in and out

If you sell tickets or run an events app, you can add EventPulse without building anything crowd-related yourself. Each buyer gets a personal live page that guides them to the quietest gate on the way in and the fastest way out afterwards. You share the link in your own ticket email or app, so they don't need a new account.

1. Get a keyThe event's organiser creates one in the organiser console and gives it to you.
2. Register each buyerWhen a ticket is sold, send us their email and the event. You get their live link back.
3. Share the linkPut it in the ticket confirmation or app. It updates by itself from arrival to the last exit.

Getting started

Every request carries the key in a header. Keep it on your server: a key in a web page or mobile app can be copied by anyone.

curl -H "X-API-Key: ep_live_…" https://your-eventpulse-host/partner/v1/events

Authorization: Bearer ep_live_… works too. All requests and responses are JSON.

What a key can reach

A key acts for the organiser who created it and reaches only the events at that organiser's venues. It can read a buyer's live status only if that buyer was registered with the same organiser's keys. The organiser can revoke a key at any time, and it stops working at once. Links already given to buyers keep working.

Endpoints

GET/partner/v1/events

Your events, soonest first, with where each is in its life right now (upcoming, running or finished).

{
  "hour": 96,
  "events": [
    { "event_id": "E5", "name": "Semi Final", "venue_zone_id": "Z01", "venue_name": "Central Stadium",
      "lat": 19.0762, "lng": 72.878, "start_hour": 102, "end_hour": 105,
      "expected_attendance": 52000, "state": "upcoming" }
  ]
}
POST/partner/v1/attendees

Register a ticket buyer and get their personal live link. Call it when the ticket is sold. Calling again for the same email and event returns the same link, so retries are safe.

curl -X POST -H "X-API-Key: ep_live_…" -H "Content-Type: application/json" \
  -d '{"event_id": "E5", "email": "buyer@example.com"}' \
  https://your-eventpulse-host/partner/v1/attendees

{
  "attendee_token": "3f9c1a7b2e40",
  "event_id": "E5",
  "event_name": "Semi Final",
  "live_link": "https://your-eventpulse-host/status.html?token=3f9c1a7b2e40",
  "already_registered": false,
  "email": "not_requested"
}
FieldMeaning
event_idOne of your events, from the list above.
emailThe buyer's email. It identifies the registration; it is never returned by the status endpoints.
send_emailOptional, default false. Set true to have EventPulse email the link as well as returning it.

The email field in the reply says what happened to the email: not_requested, sent, simulated (no mail server configured on this deployment), skipped (one went out moments ago) or failed.

GET/partner/v1/events/{event_id}

Live conditions for one event, if you want to show them inside your own app: the event state, each gate's status and load, how full the venue is, the best exit once it ends, and advice, a sentence you can show your users as is.

{
  "event_id": "E5", "event_name": "Semi Final", "venue_name": "Central Stadium",
  "event_state": "exiting", "hours_since_end": 0,
  "inside": { "people": 31200, "capacity": 60000, "pct": 52.0 },
  "gates": [ { "gate_id": "Z01-G2", "name": "North Gate", "live_status": "open", "load_ratio": 0.62, "out_of_service": false } ],
  "best_exit": { "gate_id": "Z01-G2", "name": "North Gate", "live_status": "open", "reason": "…" },
  "advice": "Semi Final has ended. Leave via North Gate: it is the quickest way out right now."
}
GET/partner/v1/attendees/{attendee_token}

The same live view for one buyer you registered: exactly what their live link shows right now, plus advice.

Limits and errors

StatusWhen
400Something in the request is wrong, such as an invalid email. detail says what.
401No key, or the key is wrong or revoked.
404The event or buyer doesn't exist, or isn't reachable with this key. These look the same on purpose.
429More than 120 requests a minute on one key. Wait a moment and retry.

An organiser can have up to 10 active keys. Use one per app or environment, so one can be revoked without breaking the others.

Privacy

The live link is the buyer's credential for their page, so treat it like the ticket: send it only to that buyer. Buyers' positions are never available through this API. If a buyer chooses to share their location anonymously to help map crowds, it only ever appears as counts for groups of three or more people.
